# 同一間教室

2D 校園體驗遊戲。玩家變成四年二班的一位同學，過他的一個早上；玩完後用「支持模式」再過一次同一天，比較老師和同學的做法改變後，有什麼不一樣。

線上遊玩：https://daimg49-gif.github.io/same-classroom/

## 內容

| 角色 | 關卡 | 五個時刻 |
|---|---|---|
| 品睿 | 想得太快的一天 | 講第三遍的數學課、紙杯電話小組、下課的卡牌圈、回到原班、寫不完的作文 |
| 可晴 | 感受太強的一天 | 畫歪的一筆、82 分的考卷、踩線的那一球、等不到主人的狗、大家的小老師 |

- 對象：國小三到六年級普通班學生，一位角色約 8 分鐘
- 玩的過程只描述感受，結算頁才說明角色的經驗來自一部分資優生
- 單一 HTML，不需要安裝；只在玩家自己的瀏覽器記錄「玩過哪一關」，不上傳任何資料

## 修改

劇本和參數都在 `index.html` 第一個 `<script>` 的設定區：`LEVELS`（角色與時刻）、`CFG`（體驗模式／支持模式的參數）、`WARM`（暖身）、`REVEAL`（結算說明）。

本遊戲由Peiching開發，角色與情境均為虛構。「換環境再玩一次」的設計參考《認識多元的世界》（chuoneone，CC BY 4.0），程式為重新撰寫。
