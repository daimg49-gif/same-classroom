# 同一間教室

2D 校園體驗遊戲，給普通班同學玩。玩家變成四年二班的一位資優生，過他的一個早上，看見他的長處、困難，以及心裡沒說出口的話。

線上遊玩：https://daimg49-gif.github.io/same-classroom/

## 內容

| 角色 | 關卡 | 五個時刻 |
|---|---|---|
| 品睿 | 想得太快的一天 | 講第三遍的數學課、紙杯電話小組、扣錯的扣子、從資優班回來、時光機作文 |
| 可晴 | 心裡的話說不出口的一天 | 畫歪的一筆、82 分的考卷、「你很慢耶」、等不到主人的狗、說不出口的「等一下」 |
| 書恆 | 一定要照順序的一天（資優＋自閉症，雙重特殊） | 被移動的桌子、說不出口的答案、講不完的捷運、改掉的體育課、不能改的規則 |

- 對象：國小三到六年級普通班學生，一位角色約 8 分鐘
- 切身體驗：每個時刻都有小遊戲或畫面特效（老師講話慢到按鈕按不下去、描線時手會抖、要按住才說得出口、噪音閃爍、畫面歪斜），開始前可勾選「減少閃爍與晃動」
- 結算頁：每個時刻的心情圖表、可展開的時刻細節、「他們是誰」與「為什麼需要資優班」、可以怎麼看待他們
- 單一 HTML，不需要安裝；只在玩家自己的瀏覽器記錄「玩過哪一關」，不上傳任何資料

## 修改

劇本和參數都在 `index.html` 第一個 `<script>` 的設定區：`LEVELS`（角色與時刻）、`CFG`（心情恢復速度、念頭出現頻率）、`WARM`（暖身）、`ABOUT`（結算頁的說明文字）。

本遊戲由Peiching開發，角色與情境均為虛構。
